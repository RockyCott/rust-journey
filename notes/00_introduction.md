# Introduction

## What's Rust?

Rust is a cool programming language.

Rust is a low-level programming language. It's multi-paradigm, supporting functional, imperative, and object-oriented programming styles.

Rust es un lenguaje de programación moderno y poderoso, diseñado para escribir código seguro, rápido y confiable.


Aunque es un lenguaje de bajo nivel (como C o C++), Rust también es multiparadigma, lo que significa que se puede programar en varios estilos: funcional, imperativo e incluso orientado a objetos, dependiendo de lo que más convenga.

_"No importa qué tipo de código escribas hoy, Rust te da herramientas para ir más allá, programar con confianza y explorar nuevos territorios en el desarrollo de software."_ — The Rust Book

## Herramientas útiles del ecosistema de Rust:

- `Cargo`: Es el sistema de construcción y el gestor de paquetes de Rust. Si sabemos de JavaScript, podemos pensar en `cargo` como el equivalente a `npm`. Ayuda a crear proyectos, gestionar dependencias y compilar tu código.

- `Rustfmt`: Es una herramienta que formatea el código automáticamente siguiendo una guía de estilo oficial. Ideal para mantener el código limpio y uniforme, sin tener que pelear por los espacios o llaves mal puestas.

- `rust-analyzer`: Esta herramienta mejora la experiencia en editores de texto y entornos como VS Code. Proporciona autocompletado, errores en tiempo real, información sobre tipos, y más.

## What can i use Rust for?

Rust es un lenguaje versátil que ya se usa en producción para crear todo tipo de software, por ejemplo:

- Command line tools (como ripgrep o exa)
- Web services (hay frameworks como Actix, Rocket o Axum)
- DevOps tooling
- Embedded devices
- Audio and video analysis and transcoding
- Cryptocurrencies
- Bioinformatics
- Search engines
- Internet of Things applications
- Machine learning
- ...
